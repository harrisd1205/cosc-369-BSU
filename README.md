# Drum Practice Tracker

A software application designed to help drummers organize their practice sessions and track their musical progress.

## Project Description

The Drum Practice Tracker allows musicians to record their practice sessions, track exercises and songs, monitor tempos, and set practice goals.

## Planned Features

* Record practice sessions
* Track practice duration
* Track exercises and songs
* Record BPM/tempo progress
* Organize practice by category
* View practice statistics
* Set practice goals
* Track progress over time
